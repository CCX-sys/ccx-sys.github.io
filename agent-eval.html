我的工作

  1. 01

    任务拆解与测试集建设

    拆解建筑方案设计与表达需求，按 L1–L4 任务复杂度组织题集，配套 Prompt 和多模态输入，统一任务分类、执行及评分标准。

  2. 02

    评测设计与评分标准

    撰写《模型评测文档》，制定 Rubric 打分细则和 GSB 盲测对比方法，形成可重复执行的判断依据。

  3. 03

    标准执行与评分校准

    制定统一输入、参数、执行流程和结果记录方式的 SOP；开展团队培训，持续校准评分口径与复核标准，减少沟通和返工。

  4. 04

    结果交叉分析与问题归因

    分析测试运行数据，按任务拆解、多轮协作、局部修改和视觉生成整理 Bad Case，形成能力边界判断并设计工具协同方式。

沉淀的成果

形成《能力边界诊断报告》《建筑 AI Agent 评测规则》与 Bad Case 归因库，将测试流程、评分口径和复盘方法用于后续选型与任务复用。
